# Clip Studio design

The image concept for 1.5.6 was generated with the built-in image-generation tool, then implemented as responsive HTML/CSS/JavaScript. It is a visual reference; no screenshot bitmap is embedded in the UI.

Design brief: premium straight-on desktop UI for a focused video clipping/publishing app, near-black charcoal surfaces, warm ivory editorial headings, muted periwinkle controls, narrow sidebar with only Vyra Clips / Projects / AI Tasks, four studio views, source import alongside queue, exported clips below, no starfield, neon glow or decorative hero photography. The original logo remains.

Shared tokens: background #101112, surface #17181a, text #f3eee5, border #2e3137, accent #b4bcf4. Serif headings use Georgia; controls and body use Segoe UI with system fallbacks. Actual footage supplies the only content imagery. Empty screens contain no fictional clips or performance data.

All existing account, review, caption, timing, import, deletion and update controls remain available. Source scouting is optional and collapsed. General-assistant navigation/actions are removed from the rendered interface. Older saved conversations are preserved for backup compatibility and are not opened from this UI.
